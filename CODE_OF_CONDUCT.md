# Code of Conduct

RIAL FOOD WORLD S.L. adopts the **Contributor Covenant v2.1** as its Code of Conduct for all contributors, collaborators, and maintainers of this repository.

The full text is available at the official source:

- English: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Español: https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/

## Scope

This Code of Conduct applies within all project spaces — repositories, issue trackers, pull requests, code reviews, documentation, and any public or private channel where a contributor represents the project.

## Enforcement contact

Reports of unacceptable behavior may be sent privately to:

**conduct@rialfoodworld.com**

All complaints will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter.

## Enforcement guidelines

We follow the Community Impact Guidelines published alongside the Contributor Covenant v2.1:

1. Correction
2. Warning
3. Temporary ban
4. Permanent ban

Each escalation is documented and communicated to the involved parties.
