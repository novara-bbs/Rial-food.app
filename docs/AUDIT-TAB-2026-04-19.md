## Cluster 1 — Diccionario (Wave 0 + Wave 1 + Wave 2)

### Wave 0 — Bug sweep + dead-code purge

**Commit:** `74b4bfa` `fix(audit-wave-0): S3 Diccionario — bug sweep + dead-code purge`
**CHANGELOG:** `[1.5.45]`

Files: `FoodDictionary.tsx`, `AddMeal.tsx`, `BarcodeScanner.tsx`, `PortionSelector.tsx`
i18n: `portionSelector.modeGroupLabel` × 2 locales (1562 → **1563**).

**Bugs fixed:**
1. `FoodDictionary.tsx` — phantom `data?` prop removed from Props type (silently unused); 2 `navigateTo(…, { prefillIngredient })` calls simplified — second arg was always dropped by `NavigationContext`'s `(screen: string) => void` signature (TypeScript-silent bug, comment added to prevent re-introduction).
2. `AddMeal.tsx` — debounce race: `clearTimeout(searchTimerRef.current)` moved before the `searchQuery.length < 3` early-return so a stale `"pizz"` timer no longer fires after backspacing to `"pi"`.
3. `AddMeal.tsx` — map key collision: `key={food.id}` could clash when a local ingredient and an OFF product share the same numeric id; fixed with `keyPrefix = food.isApiResult ? 'off' : 'loc'`.
4. `AddMeal.tsx` — multi-queue banner `<div role="status" aria-live="polite">` so screen readers announce "+N añadidos • Deshacer".
5. `BarcodeScanner.tsx` — silent `catch {}` on OFF lookup → `logger.warn('BarcodeScanner OFF lookup failed', { barcode, error })`.
6. `BarcodeScanner.tsx` — `errorMsg` state wrapped in `<p role="alert">` for transient scanner errors.
7. `PortionSelector.tsx` — mode toggle converted from 2 bare `<button>` elements to `<div role="radiogroup" aria-label={…}> + role="radio" aria-checked` (canonical WAI-ARIA exclusive binary selection).
