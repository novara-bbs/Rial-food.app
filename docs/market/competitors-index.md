# Competitors index — 35 apps clasificadas

> Snapshot: 2026-04-17. Mantenimiento: revisar cada 6 meses, ad-hoc si una app nueva entra al top-10 relevante.

Clasificación por **Tier** (relevancia estratégica para RIAL) y por **categoría funcional**.

## Leyenda

| Tier | Significado |
|---|---|
| **A — Directo** | Compite por el mismo user-job que RIAL (nutrición + recetas + planner + wellness). Fichas deep-dive obligatorias. |
| **B — Indirecto** | Captura parte del user-job pero no todo. Amenaza relevante, ficha si tiene patrón único. |
| **C — Adyacente** | Territorio cercano (wearables, shopping, social food) que puede eclipsar RIAL si no se atiende. Entrada breve aquí. |

## Tier B — Indirectos (entrada corta, sin ficha completa salvo excepciones)

### B1 — Tracking alternativos
- **Lose It!** — US, $39.99/año Premium. Freemium más generoso que MFP (unlimited log, barcode en free). Buen fallback para users que huyen de MFP tras subida de precio.
- **FatSecret** — AU, Premium $6.99–14.99/mo. **Único con photo recog + barcode en free tier**. DB comunitaria (confiabilidad variable). Cross-country pricing variable.
- **Carb Manager** — US, nicho keto / low-carb. Fuerte en comunidad keto, database keto-optimizada.
- **WeightWatchers (WW)** — US, big incumbent. $368M rev 2025. Puntos system, reforma 2024-25 para incluir GLP-1 companion. Brand > tech.

### B2 — Recetas + planner alternativos
- **Samsung Food** (ex-Whisk) — KR/JP, breadth extrema (recetas + scan + shopping + IoT cocina Samsung). Ejemplo del "breadth trap" — mucho, mal integrado.
- **Yummly** — US, acquired Whirlpool 2017. Recipe discovery + shopping Instacart. Foco premium visual.
- **NYT Cooking** — US, brand premium. $5/mo. Curaduría editorial > algoritmo. No planner, no tracking.
- **Cookpad** — JP/global, 60M+ users, 70+ países. User-generated recipes, fuerte en APAC y LatAm.
- **Kitchen Stories** — DE, importer de recetas benchmark histórico. Visual + step-by-step fotos.
- **Plan to Eat** — US, $5.95/mo. Drag & drop calendar + import web. Fuerte en familias.
- **Ollie** — US, 2026 top family planner. Pantry photo scan, kid-friendly swaps, leftover reuse ("Monday chicken → Wednesday soup").

### B3 — Meal-kit / grocery adjacency (no son apps puras pero capturan user-job)
- **HelloFresh / Factor / Blue Apron** — delivery kits, reducen fricción cook step completamente.
- **Instacart / Walmart+ / Amazon Fresh** — grocery delivery APIs que usan MFP+, Fitia, Eat This Much.

### B4 — Social / creator-led food
- **Pinterest** — recipe save-first, referencia UX para "see it → save it → plan it". Dominio visual discovery.
- **TikTok + Instagram Reels** — 49% US consumers usan TikTok como search, 65% Gen Z. **Descubren aquí, planean en otra app**. Gap monetizable.
- **Pluck** — $11.99/mo. Extrae recetas de video con 5 AI modes. Prueba de concepto del "TikTok → plan" pipeline.

## Tier C — Adyacentes (monitoreo; no deep-dive)

### C1 — Wearables / biomarkers
- **Oura Ring** — 50+ metrics, $5.99/mo + ring $349-499. Sleep gold standard, integración Dexcom Stelo glucose. Oura Advisor = AI coach biomarker-informed.
- **Whoop 5.0 / MG** — ver ficha deep-dive (subido a Tier A por amenaza).
- **Apple Fitness+ / Apple Health** — ecosistema iOS, datos pasivos. Integración futura obligatoria RIAL Q6+.
- **Samsung Health** — #1 Health & Fitness en Alemania (abril 2026), integración device nativa.
- **Google Fit** — integrador Android, data-only, no coaching.
- **Fitbit** — legacy, post-Google acquisition en declive vs Whoop/Oura.
- **Strava** — #1 Health & Fitness Spain (abril 2026 Play Store). Running + social. No nutrición.
- **Runna** — coaching running IA, nicho adyacente.

### C2 — Biomarkers consumer / CGM
- **ZOE** — microbioma + test en casa. Premium segment.
- **Levels** (Abbott Lingo) — CGM consumer, observabilidad glucosa. Convergencia con Oura + Whoop.
- **Nutrisense** — CGM-as-service premium.
- **BloodGPT / Function Health** — lab results → nutrition recomendations.

### C3 — Mood / hábitos
- **Daylio** — mood tracker gamificado. Referencia UX para Real Feel Diary de RIAL.
- **Finch** — gamificado self-care, target Gen Z.

### C4 — Shopping / pantry
- **Bring!** — lista de compra colaborativa DACH + LatAm. Referencia UX lista.
- **AnyList** — lista compra + recipes + meal plan, iOS premium.

### C5 — Otras apps que suben (monitorear)
- **PlanEat AI** — según rankings 2026, top spot en algunos posts de industria. Propuesta: "removes the hardest part of healthy eating: daily decision-making". Investigar en siguiente snapshot.
- **Pivot** — integra Whoop con nutrición. Señal de que hay gap bien monetizable.

## Clasificación por geografía primaria

| Geografía | Apps líder | Nota para RIAL |
|---|---|---|
| **US / global** | MyFitnessPal, Cronometer, MacroFactor, Noom, Cal AI, Bevel, Whoop, Simple, Eat This Much, PlateJoy, Paprika, Mealime, Lose It | Mercado saturado. Entrar requiere ICP claramente diferenciado. |
| **España / LatAm** | **MyRealFood** (ES), **Fitia** (LatAm), Yazio (creciendo) | **Sweet spot RIAL**: cocina mediterránea + real-food identity. Aprovechar i18n ES nativo. |
| **Alemania / DACH** | Yazio (DE home), Fastic (DE), Samsung Health (#1), Bring! | Mercado más grande Europe (43.7% share). Entrada difícil sin localización DE. |
| **UK** | Lifesum (fuerte), MFP | Mercado premium dispuesto a pagar. |
| **Francia** | **Yuka** (FR home), ZOE | Mercado concienciado ingredientes. Yuka-like filosofía viable. |
| **Japan / APAC** | Cookpad, Samsung Food | No prioritario para RIAL v1. |

## Clasificación por modelo de negocio

| Modelo | Apps | Implicación para RIAL |
|---|---|---|
| **Freemium ads + subscription** | MFP, Yazio, Lifesum, Fitia, Lose It | Standard. Ads reducen percepción premium. |
| **Subscription puro (no ads)** | Cronometer, MacroFactor, Noom, Mealime, Eat This Much, PlateJoy | Premium feel. RIAL debería tender aquí cuando tenga RevenueCat estable. |
| **One-time purchase** | Paprika | Contracorriente; fuerte en power users anti-subscription. |
| **Pay-what-you-want** | Yuka | Genera trust enorme, requiere escala masiva para sostener. |
| **Device + subscription** | Whoop, Oura | No aplica a RIAL pure software. |
| **Coaching humano + app** | Noom, WW, Simple | Costoso de escalar. RIAL defiere a AI Coach. |
